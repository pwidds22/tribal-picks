# Add Anti-Pattern: $ARGUMENTS

## Instructions
1. Open `CLAUDE.md`
2. Find the "Anti-Patterns" section (or create one)
3. Add the new anti-pattern under the appropriate category
4. Format as: `- **DON'T** [what not to do] - [why or what to do instead]`
5. Save the file

## Categories
- **Game Logic** - Scoring mistakes, bracket calculation errors
- **Data** - Hardcoded castaways, wrong episode data
- **Architecture** - Wrong imports, impure functions in core/
- **Database** - Schema issues, Supabase patterns
- **UI** - Component patterns, loading states
- **Survivor-Specific** - Show rules misunderstood (idols, medevacs, etc.)

This is part of the feedback loop - when Claude Web catches a mistake, add it here so it doesn't happen again.
